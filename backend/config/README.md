# Backend Config

This folder now contains the Django project scaffold:

- `settings/base.py`
- `settings/local.py`
- `settings/staging.py`
- `settings/production.py`
- `urls.py`
- `asgi.py`
- `wsgi.py`
- `celery.py`

Install backend dependencies before running the project:

```bash
pip install -r backend/requirements/local.txt
```
