# Operating Checklists

Use these checklists as a daily, weekly, or monthly operating manual.

They are written for real users who need to know:

- What should I open first?
- Which counts should I trust?
- What should I clear today?
- When should I stop and escalate?
- What evidence should I keep?

## How to Use a Checklist

1. Start with the first page listed in the checklist.
2. Work through blocked items before warnings.
3. Use the linked workflow when the task crosses multiple pages.
4. Stop at any **Do not continue if** condition.
5. Record notes when a decision affects payroll, access, compliance, or employee records.

## Common Operating Rhythm

| Frequency | What to do |
| --- | --- |
| Daily | Clear urgent dashboard queues, employee lifecycle actions, documents, attendance, leave, and notification failures. |
| Weekly | Review access, support permissions, user changes, security posture, and audit exceptions. |
| Monthly | Prepare payroll, lock inputs, calculate, review, publish outputs, and hand off to finance. |
| Before launch | Confirm tenant readiness, user access, notifications, payroll rails, public app URL, and audit evidence. |
