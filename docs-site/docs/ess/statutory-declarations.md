# Tax Declarations

Use Tax Declarations to maintain income tax declarations and proof documents for payroll calculation.

![ESS statutory declarations](../assets/screenshots/ess/statutory-declarations.png)

## Page Purpose

The page captures tax declaration information in a structured way so payroll can calculate tax deductions with the latest employee-provided details.

## Main Sections

| Section | What it shows | How to use it |
| --- | --- | --- |
| Tax profile | Employee tax context and active year. | Confirm the year and employee profile before editing. |
| Declaration detail | Declaration categories, amounts, and status. | Add or update declarations before submission. |
| Proof documents | Documents attached to declared items. | Upload proof where required. |
| Payroll consumption | Whether payroll has consumed the declaration. | Avoid late edits after payroll cutoff unless HR asks. |

## Controls

| Control | Purpose |
| --- | --- |
| Start or update declaration | Open the editable declaration flow. |
| Save declaration | Save the current values without final submission where supported. |
| Submit declaration | Send declaration for payroll or HR review. |
| Upload proof | Attach proof to the selected declaration item. |

## Declaration states

| State | Meaning | What to do |
| --- | --- | --- |
| Draft | You started but did not submit. | Complete and submit before cutoff. |
| Submitted | Sent for payroll/HR review. | Wait for review. |
| Accepted | Approved for payroll use. | No action unless your situation changes. |
| Rejected | Reviewer found an issue. | Read the reason, correct values or proof, and resubmit. |
| Consumed by payroll | Payroll has used the declaration. | Ask HR before changing it. |
| Locked | Editing is closed for the period/year. | Contact HR if a correction is urgent. |

## Before submitting

- Confirm the tax year.
- Confirm amounts match your proofs.
- Upload proof only under the correct category.
- Save a copy of proof files for your records.
- Submit before the cutoff shown by HR.

## Good Practice

- Select the correct tax year before entering values.
- Keep proof files named clearly.
- Review declaration totals before submitting.
- If payroll already consumed the declaration, ask HR before making corrections.

## FAQ

### Can I change a declaration after payroll cutoff?

Only if the page is still editable or HR reopens it. If payroll has consumed it, ask HR before making changes.

### What happens if proof is rejected?

Read the rejection reason, correct the proof or amount, and resubmit before the next payroll cutoff.
