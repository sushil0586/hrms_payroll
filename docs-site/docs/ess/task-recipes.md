# ESS Task Recipes

Use these recipes when you know the task but not the screen.

## Download A Payslip

1. Open **ESS > Payslips**.
2. Search or filter by year if required.
3. Select the payslip record.
4. Review gross pay, deductions, net pay, and publication status.
5. Use **Download payslip**.
6. Confirm the downloaded file opens correctly.

## Check If Payroll Needs Your Action

1. Open **ESS > Overview**.
2. Review **Today’s priorities**.
3. Open any document, tax, leave, attendance, or notification item marked pending, rejected, unread, or action required.
4. Complete the source action from the linked page.
5. Return to Overview and confirm the item no longer appears as pending.

## Upload A Required Document

1. Open **ESS > Documents**.
2. Find the required document type.
3. Read the accepted file format and rejection reason, if shown.
4. Select the document file.
5. Submit the upload.
6. Return to the document list and confirm the status changed to uploaded or pending review.

## Re-Upload A Rejected Document

1. Open **ESS > Documents**.
2. Filter or scan for rejected documents.
3. Read the rejection note carefully.
4. Upload a corrected file.
5. Check that the new version is visible in document history.

## Submit A Tax Declaration

1. Open **ESS > Tax Declarations**.
2. Select the active tax year.
3. Review declaration sections and proof requirements.
4. Add or update declaration amounts.
5. Upload proof documents where required.
6. Save or submit according to the page action shown.
7. Reopen the declaration and confirm the status.

## Correct A Tax Declaration

1. Open **ESS > Tax Declarations**.
2. Select the active tax year.
3. Check whether payroll has already consumed the declaration.
4. If editable, update the declaration and proof.
5. If consumed or locked, contact HR with the correction needed.
6. Reopen the declaration after HR action and confirm the latest status.

## Review A Notification

1. Open **ESS > Notifications**.
2. Filter by unread or action-needed notifications.
3. Open the notification detail.
4. Read the message, source context, and any linked workflow.
5. Mark it read or complete the source action.

## Prepare Before Payroll Cutoff

1. Open **ESS > Overview**.
2. Confirm profile, documents, leave, attendance, and tax cards do not show pending issues.
3. Open **Documents** and check there are no rejected required documents.
4. Open **Tax Declarations** and confirm the active year is submitted or accepted where required.
5. Open **Notifications** and review unread or failed items.

## When To Contact HR

Contact HR when:

- A payslip is missing after payroll publication.
- A document rejection reason is unclear.
- Tax declaration proof is correct but remains rejected.
- Leave balance does not match approved leave history.
- Attendance shows incorrect data after your regularization was approved.
