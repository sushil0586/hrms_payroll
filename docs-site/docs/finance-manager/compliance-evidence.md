# Compliance Evidence

Use Compliance Evidence to review statutory liability and filing proof generated from payroll output.

![Finance compliance evidence](../assets/screenshots/finance-manager/control-center.png)

## Page Purpose

Compliance Evidence gives finance a structured way to verify statutory files before filing, payment, or audit review.

## Main Sections

| Section | What it shows | How to use it |
| --- | --- | --- |
| Statutory liability | Filing rows and statutory packs generated from payroll output. | Confirm statutory evidence exists for the period. |
| Provider delivery | Submitted provider deliveries and reconciliation status. | Check if filed data has reached and reconciled with provider systems. |
| Compliance shortcuts | Challan proof, statutory deductions, statutory filing export. | Download supporting files for finance review. |

## Controls

| Control | Purpose |
| --- | --- |
| Export filings | Download statutory filing status data. |
| Challan proof | Open challan reconciliation proof. |
| Statutory deductions | Download deduction details. |
| Review receipts | Open provider filing receipts. |

## Review Checklist

- Filing rows exist for the payroll period.
- Statutory deduction totals match payroll output.
- Provider delivery is reconciled or explanation is recorded.
- Challan proof is available where required.
- No rejected or dead-lettered provider event remains unexplained.

## Compliance review flow

1. Confirm payroll run and statutory period.
2. Export statutory filing rows.
3. Compare statutory deductions with payroll register totals.
4. Open challan proof or payment proof if applicable.
5. Review provider delivery and receipts.
6. Record any manual filing or exception evidence.

## Common issues

| Issue | Action |
| --- | --- |
| Filing rows missing | Ask payroll/compliance owner to generate or re-run statutory output. |
| Deduction total mismatch | Hold filing and compare component-level deductions. |
| Provider delivery failed | Inspect provider receipt, retry status, or manual filing path. |
| Challan proof missing | Do not mark statutory evidence complete until proof or exception is recorded. |
| Wrong period | Re-export from the correct payroll run and period. |

## FAQ

### Should finance file statutory data if evidence is incomplete?

No. Either complete the evidence first or record a formal manual exception with owner approval.

### What if provider delivery is delayed?

Check retry status and provider receipts. If finance must proceed manually, keep manual evidence with the close pack.
