# Statutory Payroll

Statutory Payroll covers compliance setup and readiness for PF, ESIC, professional tax, LWF, TDS, and other country-specific requirements.

## Purpose

Use this page to maintain statutory packs, components, slabs, employer registrations, filing calendars, and readiness evidence.

## Statutory setup principle

Statutory setup must be effective-dated and location-aware. India payroll can differ by state, legal entity, salary threshold, employee category, and declaration status.

## Common statutory areas for India

| Area | Meaning |
| --- | --- |
| PF | Provident Fund employee/employer contribution. |
| ESIC | Employee State Insurance contribution. |
| Professional Tax | State-specific tax deduction. |
| LWF | Labour Welfare Fund where applicable. |
| TDS | Income tax deduction from salary. |

## Setup items

| Item | Purpose |
| --- | --- |
| Statutory pack | Country or state compliance bundle. |
| Component | Deduction or employer contribution component. |
| Slab | Threshold/rate configuration. |
| Employer registration | Employer statutory registration identifiers. |
| Filing calendar | Due dates and filing windows. |

## Workflow

1. Choose statutory pack.
2. Confirm employer registrations.
3. Review slabs and effective dates.
4. Map salary components.
5. Confirm employee statutory profiles.
6. Run payroll readiness.
7. Review statutory reports after payroll.

## Readiness checklist

| Check | Why it matters |
| --- | --- |
| Legal entity registration | Reports and filings need employer identifiers. |
| Employee statutory profile | Determines whether PF, ESIC, PT, LWF, or TDS applies. |
| State mapping | Professional tax and LWF can vary by state. |
| Slab effective date | Outdated slabs can calculate wrong deductions. |
| Salary component mapping | Deductions and employer contributions need correct components. |
| Tax declarations | TDS can depend on employee declarations and proof status. |

## Common mistakes

- Missing employer registration.
- Incorrect state for professional tax.
- Outdated slab version.
- Employee statutory profile missing.
- Tax declaration not reviewed before TDS calculation.

## FAQ

### Does statutory setup affect payroll calculation?

Yes. Statutory configuration can affect deductions, employer contributions, reports, and filing outputs.

### Should statutory warnings stop payroll?

Critical statutory gaps should be fixed before close. Non-critical warnings can proceed only when payroll/finance records an explicit exception note.
