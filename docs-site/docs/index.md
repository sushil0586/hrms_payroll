# Accerio HRMS User Guide

This guide explains how each workspace is used in day-to-day HR, payroll, compliance, and account administration.

Use the search box when you know what you are looking for, such as `payroll setup`, `add user`, `approve leave`, or `download payslip`.

If a screen shows a status or term you do not understand, open the [Glossary and Status Guide](glossary.md).

If you want to confirm whether both the normal workflow and failure path are documented, open [Practical Scenario Coverage](scenario-coverage.md).

## Who should use this guide

| User type | Main workspace | Typical work |
| --- | --- | --- |
| Platform operator | Platform Admin | Create tenants, convert leads, manage templates, review onboarding readiness. |
| Tenant admin | Tenant Admin | Manage customer account users, roles, subscription, support access, and security readiness. |
| HR admin | HR Admin | Manage employees, organization masters, leave, attendance, documents, payroll, reports, and launch readiness. |
| Finance manager | Finance Manager | Review payroll handoff, payout files, statutory evidence, provider exceptions, and audit records. |
| Employee | ESS | View payslips, upload documents, submit declarations, and check notifications. |
| Manager | MSS | Review team approvals, regularizations, and manager notifications. |

## How the documentation is organized

Each functional guide follows the same simple format:

- **Purpose**: why the page exists.
- **Use this page when**: common real-world situations.
- **What you can do**: actions available to the user.
- **Important buttons and fields**: what each control means.
- **Checks before moving ahead**: mistakes to avoid before finishing a workflow.
- **Related pages**: where to go next.

## Recommended learning path

1. Start with **Workspaces and Roles**.
2. Use the **Glossary and Status Guide** whenever a screen shows an unfamiliar term.
3. Read **Operating Checklists** if you are starting a daily, weekly, or monthly routine.
4. Read **Public Launch** when you are onboarding a new tenant or preparing go-live.
5. Read **End-to-End Workflows** when you need to finish a business process across pages.
6. Read the guide for your workspace.
7. Open the page in HRMS and compare the guide with the screen.
8. Use search for specific tasks.
9. Ask an admin if your screen does not show an expected page or button.
