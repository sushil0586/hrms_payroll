# Public Launch

Use this section when a tenant is preparing to move from setup, pilot, or sandbox use into production operations.

Public launch is not a single button. It is a controlled handoff across platform setup, account administration, HR setup, payroll setup, notifications, ESS/MSS access, finance handoff, security, and audit evidence.

## Launch Guides

| Guide | Use it when |
| --- | --- |
| [Go-Live Checklist](go-live-checklist.md) | You need to confirm whether a tenant is production-ready. |
| [First Payroll Run Guide](first-payroll-run.md) | You are running the tenant’s first real payroll cycle. |
| [Admin Handoff Guide](admin-handoff.md) | Responsibility is moving from platform/admin setup to customer operations. |

## Launch Owners

| Owner | Responsibility |
| --- | --- |
| Platform Admin | Tenant creation, setup templates, tenant activation, launch readiness gates. |
| Tenant Admin | Users, roles, support access, account settings, security posture. |
| HR Admin | Organization, employee data, lifecycle, documents, leave, attendance, notifications. |
| Payroll Admin | Payroll setup, salary setup, rules, inputs, calculations, review, outputs. |
| Finance Manager | Bank advice, statutory evidence, provider exceptions, payout and audit evidence. |
| ESS/MSS users | Employee self-service and manager approvals. |

## Launch Evidence

Keep launch evidence for:

- Tenant setup and activation.
- Tenant admin login.
- User and role assignments.
- Organization master completion.
- Employee master readiness.
- Payroll setup and first payroll run.
- Notification delivery test.
- ESS and MSS access test.
- Support access status.
- Security readiness.
- Finance handoff.
- Audit history.

## Launch Rule

Do not activate a tenant or run real payroll only because the screens are accessible. Activate only when the checklist, first payroll rehearsal, owner handoff, and evidence trail are complete.
