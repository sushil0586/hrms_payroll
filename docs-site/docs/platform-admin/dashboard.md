# Platform Admin Dashboard

The Dashboard is the command center for platform onboarding work.

## Purpose

Use the Dashboard to see what needs action before customers can become live tenants.

![Platform Admin dashboard](../assets/screenshots/platform-admin/dashboard.png)

## Use this page when

- You need a daily view of platform onboarding work.
- You want to know which leads, tenants, admin access, templates, or launch gates need attention.
- You need to open the right operational panel quickly.

## Page sections

| Section | Meaning |
| --- | --- |
| Metric summary | Counts for open actions, tenants, active tenants, onboarding, public leads, and setup packs. |
| Panel tabs | Direct navigation to Control, Leads, Tenants, Launch Readiness, Admin Access, Setup Templates, and Audit Logs. |
| Selected workspace guide | Short steps for the active panel. |
| Mission queue | Priority platform actions such as qualified leads that need conversion. |
| Tenant pipeline | Counts by tenant state and setup posture. |
| Risk radar | Signals that need operator attention. |
| Activation blockers | Tenants or gates that still block production use. |
| Command shortcuts | Fast links into common platform tasks. |
| Evidence trail | Counts and links for audit/support evidence. |

## Good practice

- Start here before opening individual queues.
- Resolve the highest-risk action first, not only the newest record.
- Use the dashboard as a navigation hub, then complete work in the specific panel.
