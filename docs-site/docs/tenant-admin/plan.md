# Plan and Billing

Plan and Billing shows subscription, edition, usage, limits, and commercial support evidence.

## Purpose

Use Plan to understand what the tenant can use, which limits are active, and where usage may block future work.

![Tenant plan and billing](../assets/screenshots/tenant-admin/plan.png)

## Use this page when

- A feature appears unavailable.
- A user sees a limit exceeded message.
- The customer asks which plan they are on.
- Usage needs review before adding users or running more payroll.
- Commercial support or audit evidence is required.

## Page sections

| Section | Meaning |
| --- | --- |
| Plan summary | Plan reference, edition, subscription status. |
| Usage meters | Current usage against plan limits. |
| Feature availability | Enabled or unavailable features. |
| Commercial support audit | Exportable evidence when allowed. |

## Common meters

| Meter | Meaning |
| --- | --- |
| Active users | Tenant users with active access. |
| Employees | Workforce size under the plan. |
| Payroll runs | Payroll processing usage. |
| Storage or documents | Document and artifact usage where enabled. |
| Support sessions | Assisted support access usage. |

## Limit review workflow

1. Open **Plan**.
2. Check subscription status.
3. Review usage meters that are close to the limit.
4. Confirm the affected module is enabled.
5. Confirm the user has the right role.
6. Capture commercial evidence if support or sales needs it.

## Common limit symptoms

| Symptom | Check |
| --- | --- |
| User cannot be added | Active user limit and role assignment. |
| Employee import is blocked | Employee limit and plan status. |
| Payroll run cannot continue | Payroll run limit, payroll module entitlement, and user role. |
| Feature is hidden | Plan entitlement first, then user permission. |

## Good practice

- Review plan limits before adding many users or employees.
- Treat commercial exports as sensitive account evidence.
- If a feature is blocked, check both plan entitlement and user role.
