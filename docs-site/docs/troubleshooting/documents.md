# Document Issues

Use this page when a document is rejected, missing, expired, uploaded under the wrong category, or not visible to the employee.

## Start Here

Open **HR Admin > Documents** for admin review.

![Documents dashboard](../assets/screenshots/hr-admin/documents-dashboard.png)

For employee upload or visibility issues, open **ESS > Documents** as the employee.

![ESS documents](../assets/screenshots/ess/documents.png)

## Document Was Rejected

Read the rejection reason first.

Common rejection reasons:

| Reason | What to do |
| --- | --- |
| Wrong document | Upload the requested document type. |
| Unreadable file | Upload a clearer image or PDF. |
| Missing page or side | Upload all required pages or front/back sides. |
| Expired document | Upload a valid document. |
| Name mismatch | Check whether employee profile or document is wrong. |
| Wrong category | Re-upload under the correct category. |

Good rejection notes should tell the employee exactly what to fix.

## Employee Cannot See Upload Request

Check:

| Check | Expected result |
| --- | --- |
| Employee user access | ESS access is active |
| Employee link | User is linked to employee profile |
| Requirement scope | Employee is in scope for the requirement |
| Document category | Requirement uses the correct category |
| Document status | Request is pending or required |

If the employee can log in but does not see the request, the requirement may not apply to that employee or the user may not be linked correctly.

## Expiry Issue

Check:

- Expiry date entered on the document.
- Requirement expiry rule.
- Whether the document is already expired.
- Whether renewal is required before payroll, onboarding, or compliance cutoff.

Do not verify an expired document unless internal policy explicitly allows it with notes.

## Wrong Document Category

If a file was uploaded under the wrong category:

1. Reject with a clear reason.
2. Ask employee to upload under the correct request.
3. If HR uploaded it, reattach or upload again under the correct document type.
4. Confirm dashboard counts are updated.

## Document Needed for Payroll or Launch

Some documents can block readiness.

Check:

- HR Admin Dashboard action queue.
- Launch readiness or launch remediation.
- Payroll Control blocker list.
- Employee profile readiness badges.

Do not proceed with launch or payroll if a required compliance document is missing and the process requires verification first.

## Verification Checklist

Before verifying, confirm:

- File opens successfully.
- Employee identity matches.
- Document type matches request.
- Required pages are present.
- Expiry date is valid if applicable.
- Notes are added if there is any exception.

## Escalation Details

Include:

- Employee name/code.
- Document category.
- Current status.
- Rejection reason.
- Whether employee can see ESS request.
- Expiry date if relevant.
- Whether payroll, onboarding, or launch is blocked.
