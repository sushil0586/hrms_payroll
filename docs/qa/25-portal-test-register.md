## Fresh Execution Status Rules

- Do not mark a Phase 3D scenario Passed from historical evidence alone.
- A scenario can reference historical proof as supporting evidence, but must have a current Phase 3D result or be explicitly Not Run/Blocked.
- Diagnostic reruns do not create new unique coverage.
- Staging security evidence and local functional evidence must remain separated.
- Skipped/conditional scenarios require explicit owner, reason and release impact.
