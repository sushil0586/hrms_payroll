## Pilot Usage Rule

For the pilot run, every user should work only through the browser UI unless a documented support runbook explicitly says otherwise. Seeds and scripts are for pilot preparation, controlled certification data, or recovery only; day-to-day user actions should happen through the product.

## Common Pilot Guardrails

- Use only the account assigned to your role.
- Do not share passwords, browser sessions, exported payroll files, or screenshots containing employee personal data.
- Confirm tenant, month, and pay group before changing payroll data.
- Download exports only when needed for validation or handoff.
- Record any confusing screen, missing warning, validation gap, or unexpected result as a pilot observation.
- Treat payroll close, payslip publication, and finance handoff as controlled actions.
