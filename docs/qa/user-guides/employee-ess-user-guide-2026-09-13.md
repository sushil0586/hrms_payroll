# Employee Self Service User Guide

Date: 2026-09-13

## Purpose

The Employee uses ESS to view personal HR/payroll information, submit requests, upload or review documents, manage declarations, view payslips, and track notifications.

## Main Workspace

- Primary route: `/ess`
- Documents: `/ess/documents`
- Payslips: `/ess/payslips`
- Statutory declarations: `/ess/statutory-declarations`
- Notifications: `/ess/notifications`

## What The Employee Can Do

- View profile information.
- Submit leave or attendance requests where enabled.
- Upload or view documents where enabled.
- Submit statutory declarations.
- View published payslips.
- Download allowed documents or payslips.
- Read notifications.

## What The Employee Should Not Do

- Do not upload incorrect statutory documents.
- Do not share payslip downloads publicly.
- Do not submit duplicate leave or declaration requests.
- Do not use another employee's login.

## First Login Checklist

1. Open ESS.
2. Confirm your name, employee code, and tenant are correct.
3. Open profile summary.
4. Open documents.
5. Open payslips.
6. Open statutory declarations.
7. Open notifications.
8. Confirm you cannot see another employee's private information.

## Payslip Workflow

1. Open Payslips.
2. Select the correct pay period.
3. Confirm payslip is marked published.
4. Open payslip preview or download.
5. Check employee name, period, gross pay, deductions, net pay, and employer details.
6. Raise a query if totals look incorrect.

## Statutory Declaration Workflow

1. Open Statutory Declarations.
2. Select declaration period.
3. Enter declaration details.
4. Attach proof if required.
5. Review entries before submitting.
6. Submit declaration.
7. Confirm status changes to submitted/pending review.

## Document Workflow

1. Open Documents.
2. Select document category.
3. Upload allowed file type.
4. Confirm upload success.
5. Verify uploaded document appears in the list.
6. Remove or replace only if policy allows.

## Leave Or Attendance Request Workflow

1. Open request page if enabled.
2. Select request type.
3. Enter date range.
4. Add reason.
5. Submit request.
6. Track approval status.

## Common Issues

| Issue | What to check |
| --- | --- |
| Payslip not visible | Payslip may not be published yet |
| Wrong employee data | Report immediately to HR Admin |
| Upload fails | File type, file size, network, required fields |
| Declaration cannot submit | Missing required fields or proof |
| Request pending too long | Reporting manager mapping or approval queue |

## Completion Criteria

An employee task is complete when:

- Submission or download succeeds.
- Status is visible.
- Confirmation appears on screen.
- Any issue is reported to HR with screenshot and period details.
