# HR And Payroll Reports User Guide

Date: 2026-09-13

## Purpose

This guide explains the main report types used by HR Admin and Payroll Finance Manager. Reports are part of payroll evidence, audit readiness, finance handoff, and statutory compliance.

## Report Categories

| Category | Primary user | Purpose |
| --- | --- | --- |
| Payroll Register | HR Admin, Payroll Finance | Full payroll summary by employee and period |
| Bank Advice | Payroll Finance | Payment file review and bank handoff |
| Payslip Publication | HR Admin | Published/unpublished/failed payslip status |
| Compliance/TDS/Statutory | HR Admin, Payroll Finance | Statutory deduction and filing readiness |
| Finance Handoff Exceptions | Payroll Finance | Items blocking finance release |
| Export Audit | Tenant Admin, Payroll Finance, Support | Evidence of report exports and source hashes |
| Provider Filing Receipts | Payroll Finance, Tenant Admin | Filing/payment provider acknowledgement |

## Standard Report Use Pattern

1. Open report catalog.
2. Select report.
3. Confirm tenant and role.
4. Select period.
5. Apply filters.
6. Review summary cards.
7. Review table rows.
8. Use pagination for long lists.
9. Export only after filters are correct.
10. Open export audit and confirm evidence.

## Certification Rule

For launch certification, a report is considered ready only when:

- Page loads from live data.
- Filters work.
- Empty state is clear.
- Pagination works where row count is high.
- Export works.
- Export audit entry exists.
- Source hash or evidence marker is available where required.
